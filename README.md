# DecoMID

Sitio web de DecoMID, un negocio de asesoría y diseño de espacios en Mérida, Yucatán.

## Vista previa

Abre `index.html` en un navegador. El sitio está hecho con HTML, CSS y JavaScript, sin pasos de compilación.

Las imágenes de `assets/referencias/` son referencias visuales; no representan proyectos realizados por DecoMID.
